The `github-mark-16.svg` artwork is the official GitHub Primer Octicons
`mark-github` icon, designed on a 16px grid:
https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg

The `github-mark-ui-*.png` files are transparent white renderings of that
artwork for the manager's small UI icons. The application uses their alpha
coverage with white on dark themes and black on light themes. Common display sizes use a matching raster;
other sizes use the 64px rendering.

Upstream license and logo usage guidance are retained in
`github-octicons-LICENSE.txt`.
